# CLAUDE.md

## Regeln

- **Build ohne Warnings:** Der Build muss ohne Warnungen durchlaufen. Neue Warnungen beheben statt unterdrücken.
- **UI-Texte auf Deutsch:** Alle sichtbaren Texte der Oberfläche (Labels, Buttons, Meldungen, Tooltips) sind auf Deutsch.
- **Icons: nur Lucide, einfarbig:** Ausschließlich Icons aus Lucide verwenden, einfarbig (`currentColor`), keine mehrfarbigen Icons oder anderen Icon-Bibliotheken.
